# 自动选择动画、全屏展示与人物窗口

## 默认执行范围

用户已将这套自主安排设为默认。用户把口播放入当前剪映工程，提供对应 SRT，并要求“按默认流程包装”“补 B-roll 和解释性动画”或同等完整包装任务时，由 agent 在本次整片或指定范围内决定动画类型、全屏展示区间、人物窗口形状、位置和切换点，直接完成设计与制作。无需用户逐句标时间、逐段选效果或另行批准常规全屏/画中画切换。

用户本次指定的保留段、只处理的区间、仅加字幕等限制优先。自主安排画面不改变口播剪切、文案与原声，不扩大时间线操作、保存/导出或外部付费授权。仅要求解释方法、分镜或独立素材时，完成对应范围。

实际剪辑第一步仍是确认对应 SRT 可读。之后结合全文论证、实际口播画面、人物与字幕位置、既有剪切/变速、必要的语义重音安排。SRT 提供句段时间，不自动提供词级精度；时序明显不匹配、必需素材无法读取或工具确实阻塞时才就具体缺口询问，常规设计判断由 agent 完成。

## 先选内容，再选布局

积木动画是内容形式，全屏展示是内容占比，圆窗/方窗是人物呈现方式；三者可以同时出现。例如“全屏积木生产线＋同步口播小圆窗”是一个完整方案，不应把这些选项机械排成互斥模板。

| 语义与观看需要 | 默认内容选择 | 人物与布局选择 |
| --- | --- | --- |
| 抽象流程、因果、输入输出、提效或机械动作，物理演示能讲清关系 | 设计积木人物/场景中的可见动作，走 Blender 本地三维流程 | 复杂过程可铺满主要画面，同步人物放小圆窗；需要手势配合时用方形窗口 |
| 软件步骤、功能证据、真实案例、长截图、图表或细小文字 | 优先真实截图、录屏与原始资料，局部放大讲解 | 内容全屏或占主要区域，人物缩成圆形小窗，避开数据、按钮、鼠标与字幕 |
| 解释少量概念，同时需要保留表情与手势 | 相关资料或动作图示与人物分区 | 方形/圆角矩形画中画，保留更多上半身，按实际留白决定大小与位置 |
| 观点、态度、情绪、个人经历或结论 | 人物主导，配与当前含义有关的重点强调或资料关联 | 保持或恢复人物较大画面，表情、手势与字幕可读 |
| 完整场景、加工过程或结果需要更多观察空间 | 让对应资料或三维场景全屏展示并保留阅读态 | 默认保留不遮挡的同步人物小窗；用户明确允许只看内容时才临时隐藏人物 |

积木只在能帮助理解时采用，不把真实产品界面、具体数据或证据换成虚构积木画面，也不强制每段都出人物动画。圆窗不固定右下角；方窗保留更多手势，小圆窗节约阅读空间，窗口形状由当前观看需要决定。若常见位置都遮挡内容，重排信息与人物区域，不缩小资料到不可读。

## 动作与切换怎么落在口播上

先按问题、原因、操作、比较、结果和结论组织语义段，再为每段记录：源字幕/原文、工程起止、观众要理解的变化、采用的内容、人物模式、切换依据、声音锚点与所需素材。计划是 agent 的制作依据，不把填表、逐场选效果或找音效的工作交回用户。

在完整观点、操作步骤或场景交界处切换，不按固定秒数、字幕条数或配额轮换。铺满画面用于需要观察过程/细节的段落；结果落稳后留出阅读时间，进入态度或结论时恢复人物主导。动作高点对齐实际接触、结果揭示或语义重音，窗口切换期间声音连续。

例如“以前在多个工具之间切换，现在一个工作流串起来”：先全屏展示分散模块与同一份素材的来回移动，人物进入小窗；讲到连接时，模块接通、素材顺序通过；结果落稳；下一段讲个人判断时恢复人物较大画面。积木适合示意机制，真实工具能力的证据用真实界面承接。

## 实现与交付

积木制作按 [Blender 流程](blender-workflow.md)，人物裁切、真实蒙版、源时间映射与内容覆盖按 [画中画执行](layouts-and-pip.md)。全屏内容需覆盖原来的大人物，再将同期人物窗口放在上层；普通透明叠加不会自动缩小底片。所有窗口沿最终口播源时序同步，新层静音，原声只保留一份。

agent 提前装配动画、布局变化和音效：主包装与必要辅助层从 00:00 起，同全片时长、画幅和帧率。完整包装的各语义段持续承接，人物主导段也有相关视觉任务。最后按现有分工一次批量导入素材库并展示，用户只负责从起点按必要层级拖入；只有明确授权才由 agent 操作时间线。

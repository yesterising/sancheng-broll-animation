# 积木动画的优化、制作与迭代

制作积木人物/机械场景、改进已有动画、复盘效果或扩展模板时读取本文件。默认沿用已跑通的免费本地路径，由 agent 完成设计、制作和具体错误修正；本次明确范围优先。实际口播任务先确认 SRT，独立动画和技能维护不误索要 SRT。全屏、圆窗/方窗仍按 [自动导演规则](automatic-direction.md) 判断。

## 当前默认制作逻辑

### 先决定画面要说明什么

把当前语义变成主体、动作、触发点和可见结果，再选择三维、二维、真实界面与人物占比。短段只需按键、指向或连接时，可用原地角色；走路只有服务表达时才制作。真实工具功能、数据和证据保留原始界面，不改画成虚构积木。每次按内容设计场景，不给所有主题重复工厂或强加固定镜头配额。

### 角色、接触与机械因果

- 硬塑料肢体使用固定骨长、刚性零件与合理关节方向；手部可用原生 IK，关闭拉伸。接触目标应定义在按钮/物件表面，依据人物与物件最终变换换算坐标，不能混用世界与局部坐标。目标超出可达范围时改站位、物件或动作，不拉长肢体补偿。
- 表演包含看目标、预备、伸手、接触、按压、停顿、松开和收手等必要阶段；按本次语义取舍。不要用整体晃动代替关节动作。当前旧角色腿/靴为整块几何，不直接套任意人体步态；需要行走时再解决髋部运动、脚跟/脚尖接触与重心，不宣称步态已跑通。
- 机械装配中的物件保持实体尺寸，明确来处、支撑、夹持、转运、放置和结果；真实显隐服务出入场，不用缩放长大冒充供料。精确解释优先明确轨迹、约束与状态切换；确实需要碰撞、掉落或堆叠时才引入动力学。
- 关键工序同用一套事件时序：底件停稳 → 取盖并转运 → 放料 → 夹具/吸盘释放并退出 → 压头接触、压合、抬起 → 成品输出。输送带、滚轴和工件的位移保持对应，设备停止时一起停止。按本故事改工序，不能把本例顺序强套到不同机械机制。

### 动作、镜头与声音共用事件

事件表记录接触、释放、到位、结果揭示和阅读停留；人物、物件、相机、灯光与音效引用同一时间基准。口播用 SRT 定语义区间、实际源片辅助重音落点；缺少词级证据时不声称逐词精准。改变时长要一起重排动作、相机和声音，不能只改总帧数。

镜头需要看清接触对象与动作路径。先安排场景开口、结构立柱、前景、字幕和人物窗口，再放机位；单纯把目标点对准画面中心无法解决遮挡。数值正确仍需在制作必要的动作帧上判断是否可读。本例曾因前立柱挡住供料/压合而改为后部支撑；这是一种修法，不是所有场景必须使用的结构。结果落稳后留出观察时间。

声音峰值对齐实际接触与动作结果：按键/回弹、吸附/放气、伺服移动、放料、压合和检测提示按需选择；电机与摩擦声可随同一位移函数的速度变化。程序合成声如实标注，不冒称实录 Foley 或某音效平台素材；使用录音素材时记录来源和许可。口播场景只保留一份原声，独立动画可只含机械声。

### 资源和工具的选择

核心为 Blender 原生模型、约束、关键帧和本地媒体合成。Rigify 可选，不把自动绑骨等同自动表演；按需要导入少量 LDraw 零件，不把整个零件库设为前置依赖。代码、模型和素材许可分别记录。本次实际导入的 DAT 文件为 CC BY 4.0，不能概括成全库 CC0；插件 GPL 也不替代零件许可。[ImportLDraw](https://github.com/TobyLobster/ImportLDraw)、[官方零件政策](https://beta.ldraw.org/documentation/policies-and-procedures/parts-library-policies-and-faq)。

免费 HDRI、环境与材质可按需取用 [Poly Haven](https://polyhaven.com/license) 和 [ambientCG](https://docs.ambientcg.com/license/) 的 CC0 资产，下载后本地制作；保持本片塑料质感与配色，不机械套写实污渍。项目上游支持声明和本机实测分开。视频大模型未在本例机器验证，不把免费权重或支持 MPS 当作稳定生产能力，不使用限额/水印试用填补当前流程。

## 以后怎样持续优化

每轮围绕实际缺陷保留最小记录：**缺陷与源帧/时间 → 解决假设 → 局部实现 → 正例及必要的失败例 → 画面观察 → 保留、修改或暂缓**。记录真实证据和遗留项，技术通过不替代用户视觉反馈。用户要求先分析时交付分析和必要的隔离验证；要求制作时完成正式素材，不停在方案或样片计划。

优先级为接触与可见因果、角色表演、镜头可读性、声音和材质灯光；完整步态、通用化与大模型接入按实际需求后置。先用同一故事比较关键修正，再用第二个不同主题验证复用，确有重复后才抽出动作库/接口。不要从一个按键动作推出任意搬运、跨角色重定向或无人监督自动导演均已实现。

将制作检查用于具体问题，不增加默认逐帧审批、固定测试片或额外整片验收。持续迭代发生在本次授权任务内；不代表对话结束后自动后台学习、定时执行或修改其它技能。

## 本地执行、缓存与中断恢复

优先复用已安装运行时，以后台进程在任务目录生成工程、序列和日志。确认实际可执行文件及版本，不仅相信旧路径；个人路径留在 `.local/runtime.json`。若进程退出且运行目录消失，先保留已完成帧与工程，核实路径；在已授权范围从可信缓存包或官方发行恢复独立运行副本后续渲。不凭退出码臆断为内存、GPU 或用户取消，不反复重跑相同失败命令。

断点恢复先确认旧写入进程已结束，沿同一工程/参数从首个缺失帧继续，使用独立日志；有编号不等于帧文件已完整写入。改变模型、相机或材质后不能混用旧帧。完成整段后核实帧范围连续，再编码、合声并报告真实完成状态。后台模式不保证 Dock 图标绝不变化，不修改用户系统设置来掩盖运行状态。

分开三维、人物窗口、重点文字和声音的依赖。只改窗口、外部文字或音效时复用三维；改物件、接触或机位时重渲受影响三维镜头。当前二维场景缓存不会自动完成三维/真实人物视频缓存适配，这部分是接入要求而非已实现功能。最终仍按既有约定交付 00:00 对齐全片素材，内部缓存不交给用户逐段摆放。

完整三维场景通常输出不透明 RGB 视频；确需透明另配置 film_transparent、RGBA 和 Alpha 编码，并处理仍铺满画面的几何背景。同步人物窗口要真实裁切/蒙版并覆盖原大人物，不能把普通透明叠加称作已缩小人物。独立动画交付可播放 MP4 和可修改工程；打包实际使用的声音/贴图，重打包替换音频时避免复用旧的已打包声音。

## 可复用的 14 秒源码示例

下列示例固定 14 秒/24fps、单人物和单个加工件。它复用旧模板几何，重建固定骨长右臂与整个工作单元，并丢弃旧动作。复制以下文件到本次 `work/` 后修改；业务工程不写回技能目录：

- [brick_factory.py](../assets/blender/brick_factory.py)：只用于生成几何种子工程。
- [press_line_remake.py](../assets/blender/press_line_remake.py)：固定骨长、原地表演、料架/吸盘/C形压机、同步皮带与五个镜头。
- [press_line_events.json](../assets/blender/press_line_events.json)：共享事件时序；帧号按 `round(t×fps)+1` 对齐 Blender 起帧，媒体时间从零开始。
- [press_line_sound.py](../assets/blender/press_line_sound.py)：依事件生成 48kHz 双声道原创机械声及事件报告。
- [pack_scene_audio.py](../assets/blender/pack_scene_audio.py)：把同一声音打包到新 `.blend`，保留原工程。

将 `blender` 替换为实际可执行文件。示例先创建新工程，默认不自动渲染整片；制作要求已明确时继续正式渲染。`--still` 仅在制作需要定位布局或本次要求检查时使用，不产生审批闸门。

```bash
blender --background --factory-startup --python-exit-code 1 --python work/brick_factory.py -- --project-dir work/seed
blender --background work/seed/brick_factory.blend --python-exit-code 1 --python work/press_line_remake.py -- --project-dir work/remake
blender --background work/remake/press_line.blend --render-anim
python3 work/press_line_sound.py --events work/remake/press_line_events.json --output work/remake/mechanical.wav
blender --background work/remake/press_line.blend --python-exit-code 1 --python work/pack_scene_audio.py -- --sound work/remake/mechanical.wav --output work/remake/press_line_with_sound.blend
```

再使用已可用的本地媒体工具按 24fps 编码完整 PNG 序列，并封装同一 WAV。已有 ffmpeg-skill 时可用其 sequence.py 和 audio.py；不要猜接口或静默安装依赖。本仓库不捆绑运行时、第三方零件库、用户视频或渲染成品。新主题和新时长由 agent 在任务副本中一起调整角色、场景、事件与声音，不把这份固定案例宣称为通用引擎。

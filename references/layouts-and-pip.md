# 布局、人物画中画与交付

## 从自动导演计划执行布局

完整包装的内容选择、全屏区间、圆窗/方窗与切换依据统一按 [自动导演规则](automatic-direction.md) 判断，无需用户逐段指定。本文负责真实人物窗口、源时间同步、图层覆盖与交付；本次更窄的范围或保留要求优先。

窗口不固定右下角：按钮、鼠标、表格数据、字幕和平台控件优先可见。圆窗更节约空间；方形窗口保留更多手势与环境。脸部保持比例与头顶余量，圆内可保留拍摄背景，只有确需去背景时才做人像分割。边框不代替真实圆形或圆角 Alpha。

布局在完整观点、操作步骤或场景边界切换，必要时连续缩放或短暂交接。交接前后取同一源时刻，避免口型跳动。开头首帧有与主题相关的主体；中间结果停留可读，不要求每帧运动。

## 人物窗口必须来自真实口播

先确定最终工程时间到源片时间的映射，包含每段源入点、裁切、速度与变速。原片经过删减时，源片第 20 秒不等于工程第 20 秒。多个窗口和转场交接始终复用该映射，不能用生成头像、静态照片或错误时间的片段代替。

对每个布局段记录：工程起止、源路径与入点、速度映射、人物裁切框、输出窗口位置与尺寸、蒙版形状和声音归属。若工程已是一条整理好的口播视频，可以直接以该视频的时间基准复用。

## 本地实现步骤

默认制作派生素材：按最终源映射取对应视频 → 保持比例裁出人物 → 缩放 → 生成圆形或方形/圆角 Alpha → 将窗口放在工程尺寸透明画布 → 按全片时序装配。静态窗口可用 FFmpeg 的 crop/scale、Alpha 蒙版和 overlay 等实际存在的滤镜组合；先看本机滤镜帮助，按具体画幅构造参数。圆角与圆形边缘需合理抗锯齿。

动态窗口可使用支持可 seek 视频媒体的已安装渲染器，或由 agent 按绝对帧号生成蒙版和窗口位置，再通过媒体工具合成。只有图形的网页 helper 不会完成真实视频解码。若只能做静态窗口，明确说明能力范围，不把静态裁切称作已做动态变形。

原生编辑器路径仅在用户授权时间线操作且真实接口支持时使用：复用同段口播、设置源时序、裁切和蒙版、调整窗口位置与大小，窗口音轨静音。不要猜测 API，不新建替代工程，不把导入权限当作改轨道权限。

**全屏底层内容要覆盖原来的大人物。** 把透明小圆窗直接叠在全屏口播上，会同时看到大人物和小人物。全屏展示段需准备对应内容层覆盖原全屏画面，再把同步窗口放在内容上方；结束后内容层退场，回到人物主导。只有明确要多窗口时才同时保留几个人物。

普通透明叠加层不会移动原片，也不会形成真实人物遮挡。需要人后文字时准备真实同步前景或动态遮罩。人物分层缺失时说明缺口，不以固定挖洞或半透明冒充。

## 全片交付约定

默认沿用已定稿口播，不改原片剪切或原声；SRT 只用作时间依据。完整包装为每个语义段安排明确视觉任务，前后承接。低强度阅读态可以保持相关稳定画面；仅有原片、原字幕或无关角标不能当作完成包装。

内部允许分场制作，最终主包装与必要辅助层均从 00:00 起、同全片时长、同画幅帧率。辅助层未出场的部分透明，主包装保持承接；全屏内容和人物层按同一基准同步。只给用户必要层级：原口播底片 → 内容/动画 → 人物小窗 → 前景强调元素（如需要）。可以在不影响复用与透明的前提下合并图层，避免多余文件。

声音只保留一份口播；全片声音连续，窗口切换不切断原声。已有烧录字幕不会自动消失，小窗内缩小的字幕不替代主字幕；需按当前授权处理主字幕，不能擅自重写或重复叠加。

完成正式素材后，只有在具备真实可用的编辑器入口时执行一次批量导入素材库。部分失败先报告，不自动重复、逐个绕过或声称已导入。导入后展示同一正式文件，用户最后对齐 00:00；只有明确授权才由 agent 放入时间线。素材导入、时间线装配和成片导出分别报告。

默认不备份原片、不另建测试剪映工程、不主动保存/另存剪映工程或导出整条口播成片。Blender 动画按三维流程保留制作文件。用户单独要求验收、草稿或导出时按其范围执行。烘焙 MOV 不是剪映原生可编辑动画；交付源码保留修改能力，但不能说窗口和文字参数导入后仍可原生编辑。
